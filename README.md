# Cantina: sistema de caixa em Java

Trabalho de Algoritmos e Programação Estruturada. Programa de terminal para o caixa da cantina: login, vendas com controle de estoque, desconto de estudante, formas de pagamento, relatório e fechamento de caixa.

- `Etapa7.java`: código completo
- `Etapa1.java` a `Etapa6.java`: o mesmo código construído passo a passo, seguindo o roteiro
- `GUIA.md`: explicação de cada etapa e perguntas para a apresentação

Requer Java 25 (usa `void main()` e a classe `IO`).
